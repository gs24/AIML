1. Introduction¶

E-news Express is an online news portal that aims to increase its subscriber base by improving user engagement on its website. The company has designed a new landing page with an updated layout and more relevant content to encourage users to subscribe to the platform. To evaluate the effectiveness of the new landing page, an A/B testing experiment was conducted in which users were randomly assigned to either the existing landing page (control group) or the new landing page (treatment group).

The goal of this analysis is to examine user behavior on both versions of the landing page and determine whether the new design leads to higher engagement and improved conversion rates. Statistical hypothesis testing is used to analyze the data and draw conclusions about the effectiveness of the new landing page.

2. Problem Statement¶

🔹Business Problem¶

E-news Express aims to improve online subscription by redesinging its landing page. The objective of this analysis is to evaluate whether the new landing page improves user engagement (time spent on page) and conversion rate compared to the existing page.

The analysis is conducted at a 5% significance level using hypothesis testing methods.

🔹Questions to Answer¶

The analysis aims to answer the following business questions:

  1. Do users spend more time on the new landing page compared to the existing landing page?
  2. Is the conversion rate higher for the new landing page than the old landing page?
  3. Does the conversion status depend on the preferred language of users?
  4. Is the mean time spent on the new landing page the same across different language users?

5. Hypothesis Testing¶

Q1: Do users spend more time on the new landing page?¶

Visual Depiction from EDA¶

Interpretation Visual inspection of the boxplot indicates that users interacting with the new landing page appear to spend slightly more time compared to those interacting with the old landing page. However, visual differences alone cannot confirm statistical significance, therefore hypothesis testing is required.

Hypothesis¶

Null Hypothesis(H0): The mean time spent on the new landing page is less than or equal to the mean time spent on the old landing page.

H0 : $\mu_\text{new}$ $\le$ $\mu_\text{old}$

Alternative Hypothesis(H1): The mean time spent on the new landing page is greater than the mean time spent on the old landing page.

H1 : $\mu_\text{new}$ $\gt$ $\mu_\text{old}$

This is one-tailed test because we are looking for greater than condition.

Test Selection¶

Independent Samples t-test is appropriate because

  • Comparing means of two independent group
  • Numeric dependent variable
  • Random assignment ensures independence
Data Preparation¶

The dataset is divided into two groups based on the landing page shown to users.
The time spent on the old landing page and the new landing page is extracted separately in order to compare the average time spent by users.

In [24]:
#Data Preparation

old = df[df['landing_page']=='old']['time_spent_on_the_page']
new = df[df['landing_page']=='new']['time_spent_on_the_page']
In [25]:
from scipy.stats import ttest_ind

t_stat, p_value = ttest_ind(new, old, alternative='greater', equal_var=False)
In [26]:
#Levene test
from scipy.stats import levene

l_stats, l_p_value = levene(new, old)
In [28]:
print(f"Levene test statistic: {l_stats}, p_value: {l_p_value}")

Levene test statistic: 7.113724153407544, p_value: 0.008950671168914445

Levene’s test was conducted to assess the equality of variances between the two groups. The p-value obtained (0.0089) is less than the significance level of 0.05, indicating that the variances are significantly different. Therefore, the equal variance assumption does not hold and Welch’s t-test is used.

In [27]:
print (f"T-statistic: {t_stat}, P-value: {p_value}")

T-statistic: 3.7867702694199856, P-value: 0.0001392381225166549

Inference¶

Significance level ($\alpha$) = 0.05

Decision Rule: Reject the null hypothesis if p-value < 0.05.

T-statistics = 3.78
p-value = 0..00013

Since the p-value (0.00013) is less than the significance level of 0.05, we reject the null hypothesis and conclude that users spend significantly more time on the new landing page compared to the old landing page.

✅ Conclusion: The new page improves subscriber acquisition.

Q2: Is conversion rate higher for new page?¶

Visual Depiction from EDA¶

In [29]:
conversion_rate = df.groupby('landing_page')['converted'].apply(lambda x: (x == 'yes').mean())

conversion_rate.plot(kind='bar')
plt.title("Conversion Rate by Landing Page")
plt.ylabel("Conversion Rate")
plt.show()

The bar chart suggests that the conversion rate for the new landing page appears higher than that of the old landing page. However, visual differences alone cannot confirm statistical significance, therefore a hypothesis test is required.

Hypothesis¶

Null Hypothesis ($H_0$): The conversion rate of the new landing page is less than or equal to the conversion rate of the old landing page.

$H_0$ : $p_{new}$ $\le$ $p_{old}$

Alternative Hypothesis ($H_1$): The conversion rate of the new landing page is greater than the conversion rate of the old landing page.

$H_1$ : $p_{new}$ $\gt$ $p_{old}$

This is one-tailed test.

A Two-Proportion Z-test is appropriate because we are comparing the proportions of a binary outcome (conversion vs no conversion) between two independent groups (old landing page and new landing page).

In [30]:
from statsmodels.stats.proportion import proportions_ztest
Data Preparation¶

The number of converted and non-converted users for both landing pages is calculated.
These counts are used to compute the conversion proportions for the z-test for proportions.

In [31]:
# Count conversions per landing page
conversion_counts = df.groupby('landing_page')['converted'].apply(lambda x: (x == 'yes').sum())
total_counts = df.groupby('landing_page')['converted'].count()

The number of successful conversions and total users for each landing page were extracted to compute the conversion proportions.

In [32]:
# Perform one-tailed Z-test (new > old)
z_stat, p_value = proportions_ztest(
    conversion_counts,
    total_counts,
    alternative='larger'
)
In [33]:
print("Two-Proportion Z-Test")
print("Z-statistic:", z_stat)
print("P-value:", p_value)

Two-Proportion Z-Test
Z-statistic: 2.4077170617153842
P-value: 0.008026308204056278

Inference¶

Significance level ($\alpha$) = 0.05
Decision Rule: Reject the null hypothesis if p-value < 0.05.

z-statistics : 2.41
p-value: 0.008

Since the p-value(0.008) is less than 0.05, we reject the null hypothesis and conclude that the conversion rate of the new landing page is significantly higher than the old landing page.

✅ Conclusion: The new page improves subscriber acquisition.

🔹 Visual Analysis¶

The plot shows the distribution of converted and non-converted users across different language groups. While some variation is visible across languages, the differences do not appear large. A statistical test is therefore required to determine whether conversion status is dependent on language preference.

Hypothesis¶

Null Hypothesis ($H_0$): Conversion status is independent of the preferred language.

$H_0$: Conversion status and language preference are independent

​

Alternative Hypothesis ($H_1$): Conversion status depends on the preferred language.

$H_1$: Conversion status and language preference are associated

A Chi-Square test of Independence is appropriate because both variables (conversion status and language preference) are categorical, and the test evaluates whether there is a statistically significant association between them.

In [35]:
from scipy.stats import chi2_contingency
Data Preparation¶

A contingency table is created to summarize the number of converted and non-converted users across different language groups.
This table is used as input for the Chi-square test of independence.

In [36]:
#Data Preparation for chi-square test
contingency_table = pd.crosstab(df['language_preferred'], df['converted'])
In [37]:
#Running the chi-square test
chi2_stat, p_value, dof, expected = chi2_contingency(contingency_table)
In [38]:
print("Chi-Square Test of Independence")
print("Chi-square Statistic:", chi2_stat)
print("Degrees of Freedom:", dof)
print("P-value:", p_value)

Chi-Square Test of Independence
Chi-square Statistic: 3.0930306905370832
Degrees of Freedom: 2
P-value: 0.2129888748754345

Inference¶

Significance level ($\alpha$) = 0.05

Decision Rule: Reject the null hypothesis if p-value < 0.05.

chi-square statistics : 3.09
p-value = 0.213

Since the p-value(0.213) is greater than 0.05, we fail to reject the null hypothesis, indicating that conversion status is independent of the preferred language.

🔭 Observation: This suggests that language preference does not significantly influence whether a user subscribes to the news portal.

✅ Conclusion: Conversion is independent of language.

Perform Visual Analysis¶

The boxplot compares engagement time across different language groups for users who interacted with the new landing page. The median engagement time appears relatively similar across languages. However, statistical testing is required to determine whether any observed differences are statistically significant.

The distribution of time spent appears similar across different language groups, suggesting that the average engagement time may not differ significantly.

Hypothesis:¶

Null Hypothesis ($H_0$): The mean time spent on the new landing page is the same for all language groups.

$H_0$ : $\mu_\text{1}$ = $\mu_\text{2}$ = $\mu_\text{3}$

Alternative Hypothesis ($H_1$): At least one language group has a different mean time spent on the new landing page.

$H_1$: Atleast one mean differs

A One-Way ANOVA test is appropriate because we are comparing the mean values of a continuous variable (time spent) across more than two independent categorical groups (language preferences).

In [40]:
from scipy.stats import f_oneway
Data Preparation¶

The dataset is filtered to include only users who were shown the new landing page.
The time spent values are grouped by preferred language to compare the mean engagement across language groups.

In [41]:
#Data Preparation for ANOVA test
english = new_page_df[new_page_df['language_preferred'] == 'English']['time_spent_on_the_page']
spanish = new_page_df[new_page_df['language_preferred'] == 'Spanish']['time_spent_on_the_page']
french = new_page_df[new_page_df['language_preferred'] == 'French']['time_spent_on_the_page']
Calculate the p-value¶
In [42]:
from scipy.stats import f_oneway

f_stat, p_value = f_oneway(english, spanish, french)

print("F-statistic:", f_stat)
print("P-value:", p_value)

F-statistic: 0.854399277000682
P-value: 0.43204138694325955

Inference¶

Significance level ($\alpha$) = 0.05

Decision Rule: Reject the null hypothesis if p-value < 0.05.

F-statistic: 0.85
P-value: 0.432

Since the p-value(0.432) is greater than 0.05, we fail to reject the null hypothesis and conclude that the mean time spent on the new landing page does not significantly differ across language groups.

🔭 This suggests that engagement with the redesigned landing page is consistent across different language users.

✅ Conclusion: Engagement time does not vary by language.
